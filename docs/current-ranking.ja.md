**v0.9.1 — 2026-11-26。公開資料による考察であり、独自の実機測定はありません。**

**v0.9.1の補足：** [性能の不整合](performance-gap.ja.md)で2023年の170HXの実測・仕様と、既存候補の比較を追加した。歴史的再発と性能不整合を別々の評価軸として扱う。以下の再発順位は維持し、実測なしの確率・合算点数は作らない。

## 1. 何を予想して順位を付けるか

本研究は、先例で見られた容量制限、共通部品利用、製造上の代替が、別世代・特定の製造群でも繰り返されたと予想する。対象は公称を超える通常データ用HBMの実装であり、各製品の全個体を同一構成と置かない。

**順位1〜3は、過去の先例から再発を予想する根拠の近さを比較した層である。** 製品目的、部品・パッケージ系列、時代背景、通常構成の成立条件を合わせて判断する。同じ層の中は同順位。実機がなくても予想は公開・更新でき、歴史や機序の情報も順位を変え得る。数値化した成功率や市場比率ではない。

**v0.9の評価軸変更：** v0.8の「物理仮説の具体性」から、先例と製造群の再発予想を主軸にした。旧値はCSVの `v08_specificity_tier` に残す。新しい実機結果による変更とは区別する。[再発仮説の背景](recurrence-hypotheses.ja.md)と[先例の日付台帳](../data/capacity_precedents.csv)を参照。

| 評価するもの | 現状 |
| --- | --- |
| 予想の順位 | 先例との機序上の近さと、候補別の製造群の予想で比較する |
| 新規予想11件の物理実装・健全性・アクセス | 全て未確認。予想順位とは別の状態として保持する |
| 具体的な当たりロットや市場比率 | 未同定。下表の製造群は予想の選択条件であり、既発見のロットではない |
| 価格による順位変更 | 検証済みの比較時系列がなく、適用していない |

通常説明にも根拠の段階がある。**対象部品の同定、同系列の正規構成、部品カタログ、算術上の例、入力未確認**を区別する。数字だけ合う低密度部品を置いて、実在の適合部品と同じ強さの反論にしない。逆に、調査で見つからない部品を存在しないとも決めない。個別の内訳はCSVの `ordinary_model_evidence` に残す。

GB級の構成例は条件付きの総容量で、観測値や期待値ではない。出典は入力の事実・外部報告を支え、メーカーがこちらの予想まで述べたことを意味しない。

### v0.8で機序を絞った点

次は[チャネル分割モデル](capacity-constraints.ja.md)における条件付き推論です。容量を同じ単位にそろえ、通常データ容量・予約分を区別し、チャネル当たりの容量配分を仮定します。密度は候補個体で確認済みの値ではありません。

### この順位にした理由と、逆転する条件

**第1層 — CMP 100-200：** 同じ採掘向けCMP系列のPascal側とAmpere側に容量制限の外部報告があり、Volta側の約6 GB構成にも同じ製品判断が再発したという予想を優先する [S02,S04a,S19]。これは歴史と用途からの予想である。対象幅は未確認なので、測定済みの帯域異常とは呼ばない。

**第2層 — A30、PG199、A800 Active、CMP 100-210、MI50、H100 64 GB：** 同じGA100系列、同じCMP用途、または同系列の正規容量違いという具体的なつながりがある。これらを部品・パッケージ群の予想へ移す。CMP 100-210は基板群とV100の正規16／32 GB比較を使えるため3→2とした [S08,S14,S33]。既知の性能改善が容量回復に変わったわけではない。H100 64 GBの64／94 GB比較は有用だが、同じ用途での反復により近いCMP 100-200より下の層へ移す。

**第3層 — H100 80 GB、RX Vega、BC-160、A30X：** H100 80 GBの第6位置は、深さ制限の反復とは異なる実装・選別仮説で、5基の有効構成と支持部材の対立説明がある [S62,S63]。VegaはRXとFrontier Editionのパッケージの違い、BC-160は適合高密度パッケージの未確認、A30Xは対象幅の未確認が、先例の移し替えを弱める。予想は残し、追加の製造経路が見つかれば更新する。

**予想は資料だけでも更新できる。** 部品の適合、時期、共通化、選別・割当てに関する新情報が、再発を予想する根拠を強めたり弱めたりする。実装確認の欄は、それを直接支える情報が得られるまで変えない。未確認という状態だけで全候補を同順位にせず、仮定上の容量の大きさだけでも順位を上げない。

| BC-160 | 元のXFX/Navi 12のボード・パッケージ群 | 適合する高密度量産パッケージが見つかり、その一部が8 GB公開へ割り当てられる |
| A30X | 正確な統合モジュールのPN・パッケージ群 | 公称24 GBを維持したまま高密度部品を使う群が現れる |

商業上の容量区分が持続する仮説と、一時的な部品代替の仮説では、予想する期間分布が違う。初期・後期のどちらが有利かは一律に決めない。設定・実装・販売のどの日付が予想に対応するかを[再発仮説](recurrence-hypotheses.ja.md)で区別する。

通常の実部品が特定された群では、その群の余剰予想を弱める。否定例が出るたび対象を無名の別ロットへ移すことはしない。新しい資料で範囲を変える場合は、元の予想と変更理由を残す。
