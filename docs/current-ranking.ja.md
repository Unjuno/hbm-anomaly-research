**v0.11.0 — 2026-11-26。公開資料による考察。独自の実機測定なし。**

## v0.11の歴史による更新

新しい[歴史調査](historical-context.ja.md)は、A800系での販売先・割当て変更、MI50の32 GB商品追加、Vega期の供給拡大計画を候補ごとに接続する。A30Xの2021年計画、PG199の公式DRIVE用途、BC-160に対する通常8 GB先行商品は、対立説明も具体化する。CMP170HXでは出荷後のVBIOS性能変更が記録され、性能差を直ちに部品差と見なせなくなる [S94–S110]。

[歴史評価CSV](../data/history_assessments.csv)の11行に、根拠となる日付、経路、予想する群、時系列上排除できる説明を記録した。既存CSVの歴史・群の予測も更新する。下記の診断区分と物理・健全性・利用可能性の状態は維持する。歴史上の動機が強まることは、特定個体の余剰メモリが確認されたこととは異なる。

## 1. 旧順位を撤回する

v0.9の順位は、先例との用途・系列の近さを主な理由にしていた。v0.9.1で性能比較を加えた後も、その順位を維持した。これは、候補の観測が普通の部品構成で説明できるかという識別を順位に反映していなかった。

**新規11仮説の1〜3位層を撤回する。** `rank_tier` は空欄にし、旧値を `v09_recurrence_tier` に保存する。単に確証がないから撤回するのではない。通常構成でも同じ観測を説明できる事例と、判定に必要な入力が欠ける事例を、類似性だけで序列化していたためである。

予想の対象は、公称容量を超える通常データ用の物理HBMである。健全な追加容量、ソフトウェアからの利用、可逆な制限、メーカーの動機は、それぞれ別の主張として扱う。

## 3. 170HXに残る、対象固有の制約

2023年の当事者レビュー [S87] は、8 GiB級の製品、デバイス表示7961 MB、4096本、ツール算出1492.99 GB/s、clpeak実測1165.79〜1355.40 GB/sを報告した。GPUクロック1410 MHz、表示メモリクロック729 MHz、CUDA版12.20。実測レンジはベクトル幅間の差であり、繰返し誤差区間ではない。ワーキングセット、負荷時クロック、温度等の欠測は[性能台帳の説明](performance-gap.ja.md)に残す。

| 対立する部品モデル | 公称容量級・幅・計算帯域 | レビューとの関係 |
| --- | --- | --- |
| 公表2 GB・2.0 Gb/s品を4基 [S93] | 8 GB級・4096本・上限1024 GB/s | 容量と幅は合うが、報告帯域には足りない |
| 研究値2.4 Gb/sを2 GB品にも認める感度分析 [S36] | 8 GB級・4096本・上限1228.8 GB/s | 実測レンジの一部は説明できる。最大1355.40 GB/sはなお上回るが、計数条件を確認する必要がある |
| 高速8 GB級部品を4基 [S01] | 32 GB級・4096本・最大1638.4 GB/s | 帯域を満たせる。一部公開という追加機序を置けば8 GB級表示も説明できる |
| 高速16 GB級部品を4基 [S01] | 64 GB級・4096本・最大1638.4 GB/s | これも説明可能。帯域だけで32／64 GBの一方は選べない |

表は実装同定ではなく条件付きモデルである。未公開の低密度高速品、定格外動作、幅の報告誤り、キャッシュ等を含む計数は対立仮説として残る。公開部品集合が全ての選択肢を網羅するとは仮定しない。研究値を含めると結論の強さが変わることも開示する。

FMAの低性能と非FMAの改善は演算制限を示唆するが、低密度HBMのカードにも実装できる制限である。余剰HBMの独立した加点にしない。また、後年の容量変更報告は、この2023年資料から行う条件付き推論に混ぜない。

## 4. 資料を調べる順序

1. **CMP 100-200の同一個体の記録を照合する。** 6 GB級という表示だけでなく、幅と帯域、部品の速度級を結ぶ。幅だけでは2 GB品の対立仮説が残る。
2. **既存個体に対応する部品情報を照合する。** MI50やA30Xについて、普通の構成で説明できる数値をもう一度比較するより、密度・速度・型番を結ぶ資料の方が判断を変える。
3. **追加位置・製造経路の仮説は、その枝を直接区別する資料を探す。** H100の第6位置、GA100派生品の実装、元OEMモジュール、適用できる部品変更記録を扱う。

この順序は、少数の資料で判断を進めるための調査方針であり、成功確率の代用品ではない。資料が存在しない場合は、その欠測を残す。実機を購入・所有しなければ仮説を更新できないという条件は置かない。

## 5. 歴史・ロット・価格をどう使うか

歴史は、候補を生む機序と対象を結ぶために使う。再発の可能性はあるが、同じ企業・世代・用途だけでは、異なる部品構成のどちらが使われたかを識別できない。

| 観測された背景 | 必要なつながり | そのつながりがない場合 |
| --- | --- | --- |
| 低密度品の不足 | 対象で認定された代替品、利用可能時期、容量設定を変更できる製造段階 | 不足一般として記録。容量予想の順位に加算しない |
| 完成済みパッケージの余剰 | 対象へ適合する部品番号・実装、再割当て前後の時点 | 共通ダイや似た基板だけで転用を認定しない |
| 製造群の違い | 元部品・改版・製造段階に沿った群と、予想される仕様差 | 販売日や販売者だけから当たりロットを作らない |
| 価格変動 | 同じ仕様・状態の時系列と、供給・需要・報道などの対立要因 | 現在は検証済み時系列不足。価格による順位変更なし |

高密度品を使う経済性があっても、余っている対象部品と認定・工程がつながらなければ製造の予想にはならない。メモリ不良による選別なら、物理余剰は予想できても健全な追加容量には逆向きの材料になる。[製造原因](manufacturing-causality.ja.md)と[歴史仮説](recurrence-hypotheses.ja.md)を参照。
