# 情報提供

[English](call-for-participants.md) · [候補一覧](current-ranking.ja.md)

対象のGPUについて、仕様、実機ログ、元の部品型番、製造時期などを共有してください。通常構成だった例や、仮説への反論も歓迎します。

**[Issueを作成する](https://github.com/Unjuno/hbm-anomaly-research/issues/new?template=quick-evidence.md)**

書くのは次の3点で十分です。

1. 対象製品・型番
2. 確認した事実（容量、幅、帯域、部品など）
3. 出典URLまたは既存ログ・写真

実機の購入・分解・変更は不要です。シリアル番号などの個体識別情報は削除してください。
