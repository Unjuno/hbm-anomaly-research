# 製造史とロット差

[English](historical-context.md) · [トップ](../README.ja.md) · [候補](current-ranking.ja.md) · [出典](sources.md)

歴史から探すのは、**高容量品を低容量品として使う合理的な理由が生じた時期**。次の三つを優先する。

## A800 / 後期GA100：販売先の変更

2022年10月末期、NVIDIAは中国データセンター需要低下に主に関係する7.02億ドルの在庫費用を計上。11月18日の提出資料にはA800の代替販売も記載される（S96）。2023年11月2日、ELSAがA800 40GB Activeの国内取扱いを発表（S99）。

**予想：** 古い大容量パッケージの再割当てがあれば、元のパッケージと後期の低容量設定が対応する群がある。通常40 GB構成も成立し、2022年A800と2023年Activeは別SKU。

## MI50：容量別製品の追加

2018年11月6日の発表はMI50 16 GB。2019年10月15日のAMD回答では、顧客要望を受け32 GB版を追加したと説明（S103, S104）。

**予想：** 32 GB版導入前後の元の16 GB製品で、部品共通化による密度差を探す。正規32 GBの販売先があり、4 GB HBM2も存在したため、強制代替は前提にしない（S101）。

## RX Vega：2017年後半の供給変化

Samsungは2017年7月に8 GB HBM2増産計画、SK hynixは10月に第4四半期のHBM2供給計画を公表（S47, S100）。

**予想：** 2017年後半～2018年の元のRXパッケージで、供給元・密度・部品型番の差を探す。増産計画は余剰在庫を意味せず、Frontier Editionとは実装パッケージが異なる（S46）。

## その他の重要な転換点

| 時期 | 事実と意味 |
| --- | --- |
| 2020年 | 16 GB HBM2E登場後もSamsungは8 GB供給継続を表明。低密度品の消滅は仮定しない（S92）。 |
| 2021～22年 | CMP売上は2.66億→1.05億→0.24億ドル。Mergeより前から縮小。完成品放出も説明になる（S95）。 |
| 2023年 | TSMCはCoWoSの工程制約を説明。未組立HBMの代替と完成パッケージ転用を区別する（S83）。 |
| 2023～24年 | Intel/AlteraのHBM2依存FPGA終息通知。最終購入や終売も不足への対応（S107, S108）。 |

**ロットの見方：** HBM製造、パッケージ組立、製品への割当て、VBIOS更新、販売は別の時点。変更できた工程に合わせて比較する。
