# Responsible disclosure and hardware safety

This repository contains descriptive research, offline calculations and reporting templates. It does not distribute firmware, privileged writes, security bypasses, fuse programming or device-modification code. Do not post exploit payloads, confidential information, proprietary binary dumps or instructions for defeating security mechanisms in issues or PRs. Report vulnerabilities privately to the relevant vendor (for NVIDIA, see https://www.nvidia.com/en-us/security/). Do not use public issues for sensitive disclosures. For vulnerabilities in this repository's own code, use GitHub private vulnerability reporting if enabled, otherwise contact the repository maintainer privately through an established channel. No modification or unsafe experiment is necessary to contribute. Follow applicable safety requirements and hardware limits.
