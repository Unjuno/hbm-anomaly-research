# HBM Anomaly Research

**公称容量・帯域・部品性能を同時に説明できる通常構成を探し、それでも残る不整合から、未公開のHBM容量を予想する研究です。**

## 今回の歴史調査：疑う経路と対象群を絞る

**v0.11は18件の出典を追加し、販売先の変更、容量別商品の追加、供給拡大計画を候補ごとに結び付けます。** 実機なしでも、出来事の前後でどの構成差が現れるはずかを予想できます。

| 調査の焦点 | 今回具体化した理由 |
| --- | --- |
| **後期GA100／A800系** | NVIDIAは2022年後半、中国Data Center需要に関係する在庫費用とA800による代替販売を開示。適合パッケージの再割当てを調べる動機が具体化した。元の在庫が大容量HBM付きだったかは別の問い [S96,S99] |
| **MI50の16／32 GB系** | 2019年のAMD直接回答で32 GB商品の追加理由を確認。工場出荷時16 GB群と容量別パッケージを比較できる。通常4 GBスタックと正規32 GBの販売経路も残る [S103,S104,S101] |
| **RX Vegaの2017年後半～2018年** | Samsungの高密度品増産とSK hynixのHBM2供給計画を照合。供給元・パッケージ変更を調べる時期を絞った。高密度余剰や実際の切替は未確認 [S47,S100] |

一方、A30Xには2021年の製品計画、BC-160の比較対象には2020年の通常8 GB製品があり、後年の不足や用途変更だけでは大容量の非公開実装を要求しません [S97,S105,S109]。歴史で更新したのは、製造経路の妥当性と比較対象です。物理余剰の順位には、容量・帯域・部品の対象固有の差を引き続き求めます。

## v0.10で訂正した推論

以前の1〜3位層は、同系列・同じ用途・過去の先例との近さで付けていました。その比較だけでは、候補に余分なメモリがある方が、普通の構成より観測をよく説明するとは言えません。**新規11候補の順位を撤回しました。** 旧値はCSVの `v09_recurrence_tier` とGit履歴に残します。

一つの具体的な反対材料は、SK hynixの2016年資料に掲載された**2 GB・1024データレーン・最大2.0 Gb/sのHBM2**です [S93]。CMP 100-200の約6 GBという報告 [S05] は、2 GB品3基でも説明できます。2 GB品を候補集合から外し、「4 GB単位で作れないから怪しい」とする推論も採用しません。対象カードへの採用・適合が確認できたという意味ではありません。

## 何を「怪しい」と判断するか

**余分な容量がない普通の構成では、対象固有のどの観測が説明できなくなるか。** この問いに答えられる材料を集めます。

| 対象 | 今ある根拠からの判断 |
| --- | --- |
| **CMP 170HX：既知例を用いた条件付きの基準** | 2023年レビューの8 GiB級・4096本・高い実測帯域は、公表された低密度部品の速度では同時に説明しにくい。大容量部品の部分公開という仮説に説明上の役割がある [S87,S93] |
| **CMP 100-200、PG199、H100 64 GB** | 対象の部品・幅・帯域などが不足。低容量や同系列という属性だけで、追加容量の順位を付けない |
| **A30X、MI50 16 GB、RX Vega、BC-160、A30、A800 Active、CMP 100-210** | 通常の容量・速度・実装モデルが残る。特にA30XとMI50は、メーカーが記載した部品クラスで容量と帯域が同時に成立する [S01,S90] |
| **H100 80 GB** | 第6位置が実メモリか支持部材かという実装の問い。見た目や全ダイ設計から追加DRAMを決めない |
| **Intel Max 1100：公式の物理参照例** | 4基の物理搭載、16 GBの3基有効、1基の恒久無効化をメーカーが明記。健全性・復元可能性とは別の事実 [S39] |

これらは成功率の順位ではありません。**今の資料で新規11候補を「隠れた容量がありそうな順」に並べる根拠は不足しています。** 不足を類似性で埋めず、通常構成に合うもの、入力不足、実装位置の問題を分けます。予想自体をやめるわけではなく、予想を区別する観測と反証条件を具体化します。

## 170HXと通常構成の違い

170HXの当事者レビューは、clpeakのベクトル幅別に1165.79〜1355.40 GB/sを報告しています [S87]。2 GB・2.0 Gb/s品4基なら、8 GB級と4096本は説明できますが、計算上の帯域上限は1024 GB/sです [S93]。対して高速な8 GB級部品4基なら、より大きい物理容量とその帯域を両立する構成を作れます [S01]。

これは選んだ公開部品集合に対する不整合です。未知の低密度高速品、定格外動作、測定の計数条件などは残ります。研究発表の2.4 Gb/sを2 GB品にも許す感度分析、測定条件の欠測、厳密な単位と容量下限の導出は[推論の方法](docs/diagnostic-inference.ja.md)に記載しています。32 GBか64 GBか、健全か、復元できるかは、この比較だけでは決まりません。

反対に、MI50の16 GB・約1 TB/sは、2016年に量産発表された4 GB・256 GB/s級HBM2を4基とする通常モデルで説明できます。A30Xの24 GB・1223 GB/sにも、2021年に説明された8 GB・3.2 Gb/s級HBM2Eを3基とするモデルがあります [S90,S01,S38,S10]。**比較相手より帯域／容量が大きいというだけでは、異常にはなりません。**

## 次の資料調査

最初に照合するのは、**CMP 100-200の同じ約6 GB個体にひも付く部品・有効幅・帯域の原記録**です。幅が3072本と分かるだけでは、2 GB品3基の説明が残ります。帯域または部品の速度級まで組にして照合します。これは判断を進めやすい資料調査の順序であり、余剰容量の確率順位ではありません。

歴史・ロット・供給事情も使います。ただし、互換部品、変更できた製造段階、対象となる期間、通常製造より転用を選ぶ理由を結び付けます。「同世代」「供給不足」「どこかのロットなら」は、それだけで候補を上げる理由にしません。公称値が普通でも、追加の無効部品が絶対にないとは限りません。別途、その実装を支持する資料を探します。

価格による順位調整はしていません。比較できる成約時系列が不足しています。発信後の価格上昇や転載も独立した技術的裏付けには数えません。
